# first-try landed

I'm Carlos. Economist by training, I spent most of my career in financial inclusion - getting financial services to people the system writes off as too risky to fund. These days I do projects in Python.

This blog comes from real projects: a multi-agent system for user behavior analysis, a churn prediction API for a Peruvian savings bank, a Django app for a composting startup, and smaller tools in between. I write when I hit something I don't quite understand yet. Writing is how I figure it out.

I grew up skateboarding. In skating, a first-try land means mastery — no reps needed, just doing a trick and landing it clean on the first attempt. This blog is named after that ideal, even though most of what I write takes many attempts to understand. The writing is the practice.

Thanks to [Bob Belderbos](https://www.linkedin.com/in/bbelderbos/) — his mentorship shaped everything I think about writing Python that actually lasts — and to [Samuel McGuire](https://www.linkedin.com/in/samuel-mcguire/) and [Carmine Somma](https://www.linkedin.com/in/carminesomma42/) for teaching Python in a way that makes you want to learn it. Finally, thanks also to [Will Dean](https://www.linkedin.com/in/williambdean/), who probably without knowing it, has inspired the format for this blog.
