# first-try landed

I'm Carlos. Economist by training, I spent most of my career in financial inclusion - getting financial services to people the system writes off as too risky to fund. These days I learn about building software in Python.

This blog is where I try to make sense of ideas that seem easier to understand while writing about them. Posts come from real projects: a multi-agent system for user behavior analysis, a churn prediction API for a Peruvian savings bank, a Django app for a composting startup, and smaller tools in between. I write when I want to understand things I don't quite yet.

I grew up skateboarding. In skating, a first-try land means mastery — no reps needed, just doing a trick and landing it on the first try. This blog is named after that, since I aspire to "first-try-land" (i.e. truly understand) the topics I write about. The process of writing is how I get there.

Thanks to [Bob Belderbos](https://www.linkedin.com/in/bbelderbos/) — his mentorship shaped everything I think about writing Python that actually lasts — and to [Samuel McGuire](https://www.linkedin.com/in/samuel-mcguire/) and [Carmine Somma](https://www.linkedin.com/in/carminesomma42/) for teaching Python in a way that makes you want to learn it.
